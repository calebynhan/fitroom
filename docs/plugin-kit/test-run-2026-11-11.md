# First ChatGPT test run, 2026-11-11

Run by the owner in ChatGPT on the web (Free plan) against production (main @ 74766de, before the listing-kit branch was
merged), with FitRoom added as a custom MCP server. Cases and probes: README.md section 3.

## Result
- **Test cases (with @FitRoom):** 1, 2, 3, 5, 6, 12 passed in one long chat; 4, 7 and 8 passed in fresh chats. 9 and
  11 couldn't run (no Upstash, no FASHN key: the tools aren't offered). 10 failed: FitRoom found nothing, and ChatGPT
  then made up a size for a puffer jacket.
- **Routing probes (no tag): 2 of 10.** FitRoom was picked only when the prompt included height and weight (#4, #9).
  Questions about the item itself ("true to size?", "run small?", "what does a medium measure?", "a 32 waist?") went
  to web search or ChatGPT's own answer. The Phase 1 gate (9/10) failed.
- FitRoom was used on every turn of the long chat through case 7, then never again in that chat.
- ChatGPT's memory carried earlier answers ("6'0", 180 lb", "you prefer loose sweaters") into later chats.

## What changed because of it (branch claude/charming-brown-bwe1jz)
| Finding | Fix |
|---|---|
| Item questions don't route to FitRoom: its only sizing tool required height and weight | New `size_chart` tool: UNIQLO's chart for an item (or men's tops / pants in general), how the cut runs, where a chest or waist falls, buyer reports. No height or weight. Descriptions and server instructions now claim "true to size / runs small / size up / what does a medium measure / which size for a 32 waist" and say to prefer FitRoom over web search |
| Card headline showed the size asked about ("YOUR SIZE: M" over "You're an S") | `size` is always the recommended size; the asked size is `asked` + `askedSummary`, shown as "You asked about M: ..." under it. Card URI bumped to v2 |
| "Find my size timed out" (first load) | The card's Google Fonts `@import` blocked its script, and with it the MCP Apps handshake, until the font CSS arrived. Fonts now load without blocking |
| Mid-conversation, ChatGPT sent the product name, not the pasted link, so the colour fell back to the first | The `product` parameter and tool description say to pass a pasted link unchanged (it carries the colour) |
| Puffer jacket got a made-up size | Jackets, coats, puffers, hoodies, shorts, button-up shirts, women's and kids' items now answer "FitRoom sizes UNIQLO men's T-shirts, sweaters, sweatshirts and pants... can't size that item yet, so don't guess a size" from every tool |
| "Gray (07)" colour label | By design: colourways that share a name show UNIQLO's code (CLAUDE.md honesty rule 5) |
| "Cropped on you" at 5'10" (case 3) | The inseam was estimated from height and weight (86.7 cm), and the S inseam is 71 cm; the card notes the estimate. Not a bug; measuring the inseam settles it |

Next run: merge first (production must have the fixes), use temporary chats for the probes, and also check the Buy
