Try-on eval

Dev only (not in the production build: npm run dev, then open /eval.html). Pick a few full-body photos of yourself; each is tried on with every garment in the set through the app's own pipeline (garment photo choice, the free Space, the sharpening composite) and scored. Photos go to the public Space like in the app and nowhere else. Each pass uses free GPU time (a free Hugging Face account allows ~5 min a day, anonymous ~2).
